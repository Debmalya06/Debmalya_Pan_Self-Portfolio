# Portfolio Website

A modern, responsive portfolio built with React and Vite showcasing projects, skills, experience, education, and certifications.

## Overview

This portfolio includes sections for:
- **Home**: Hero section with introduction
- **About**: Personal background and overview
- **Projects**: Showcase of completed projects
- **Skills**: Technical skills and proficiencies
- **Experience**: Professional work history
- **Education**: Academic background
- **Certifications**: Relevant certifications and achievements
- **Contact**: Get in touch section

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- ESLint

## Quick Start

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deployed on Render with SEO optimization and Google Analytics integration.
